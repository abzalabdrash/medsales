# Хендофф: встроить ИИ-помощника в MedPrice.kz

Этот файл самодостаточен. Его можно целиком отдать кодовому агенту (Codex,
Claude Code, Cursor) как задание — контекста в нём хватает, лазить по чату
не нужно.

---

## 1. Что уже есть

Репозиторий `medsales`. Два слоя, оба рабочие:

**`pharma/`** — парсеры на Python, собирают `data/medsales.db` (SQLite).
**`web/`** — Next.js 16 (App Router, React 19, Tailwind 4, `node:sqlite`),
двуязычный ru/kz. `npm run build` проходит, `npx tsc --noEmit` чистый.

```bash
pip install -r requirements.txt
python -m pharma.ingest_ref        # справочник препаратов из приказов МЗ РК
python -m pharma.ingest_benefits   # льготы + ATC-коды
python -m pharma.ingest_offers     # цены аптек
python -m pharma.merge             # -> data/medsales.db

cd web && npm install && npm run dev
```

> Перед `python -m pharma.merge` остановите dev-сервер: он держит базу
> открытой, и Windows не даст её перезаписать.

## 2. Задача

Сейчас в интерфейсе есть плавающая кнопка «Помощник»
(`web/components/ChatWidget.tsx`) и заглушка `web/app/api/chat/route.ts`.
**Нужно заменить их на полноценного ИИ-агента,** встроенного в интерфейс
гармонично, а не «чат сбоку от сайта».

### Что агент должен уметь

1. Принимать **фото назначения врача** и распознавать позиции.
2. Считать **стоимость курса**, а не упаковки.
3. Находить, **где дешевле**, и предлагать аналоги по ATC.
4. Говорить, если препарат **положен бесплатно** по ГОБМП/ОСМС.
5. Строить **маршрут** по аптекам и клиникам с переходом в 2GIS.
6. Отвечать **карточками**, а не простыней текста.

## 3. Главный принцип: модель не ходит в интернет

Модель работает **только** с инструментами над нашей базой. Веб-поиск — это
ровно то, что уже умеет любой чат-бот и делает плохо: он не знает
казахстанских цен, наличия и того, что положено бесплатно.

Разделение труда, от которого нельзя отступать:

| Задача | Кто делает | Почему |
|---|---|---|
| Прочитать почерк на фото | **LLM (vision)** | только она это может |
| Разобрать схему приёма в JSON | **LLM (structured output)** | естественный язык |
| Найти препарат в справочнике | код (`brand_head` + fuzzy) | нужен воспроизводимый результат |
| Посчитать упаковки на курс | код (`lib/course.ts`) | арифметику модели не доверяем |
| Оптимизировать маршрут | солвер | LLM галлюцинирует на комбинаторике |
| Объяснить результат человеку | **LLM** | эмпатия, язык, контекст |

Готовые промпты и контракт карточек лежат в `pharma/agent/`:
`prompts.py` (vision, системный промпт, объяснение маршрута) и `cards.py`
(типы карточек + JSON-схема ответа). Их можно переносить в TypeScript
как есть.

## 4. Инструменты, которые нужно дать модели

Все — тонкие обёртки над готовыми функциями в `web/lib/`.

```ts
find_drug(name, city)          // lib/drugs.ts: searchDrugs
get_drug(offerId)              // lib/drugs.ts: getDrug
find_analogs(atc, excludeId)   // lib/drugs.ts: getAnalogs   — аналоги по ATC
check_free_coverage(atc, inn)  // lib/drugs.ts: getFreeCoverage
compute_course({...})          // lib/course.ts: computeCourse — ОБЯЗАТЕЛЕН
find_service(name, city)       // lib/db.ts: getServiceLocations
list_pharmacies(city)          // lib/pharmacies.ts
place_reviews(placeId)         // lib/pharmacies.ts
```

`compute_course` вызывать **до** любого разговора о сумме. Цена упаковки без
количества упаковок вводит человека в заблуждение: «Ае-вит 1 капсула 3 раза
в день 40 дней» — это 120 капсул, четыре упаковки, а не одна.

## 5. Правила, нарушать которые нельзя

1. **Не менять назначение врача**: ни дозу, ни частоту, ни длительность.
   Мы считаем деньги и логистику, а не лечим.
2. **Аналог — только предложение**, всегда с пометкой «то же действующее
   вещество, замену согласуйте с врачом или фармацевтом».
3. **Rx помечать честно**: без рецепта не продадут.
4. **Не выдумывать цифры.** Цена, адрес, наличие берутся только из ответа
   инструмента. Пусто — так и сказать. Правдоподобная выдумка в медицине
   хуже честного «не знаю».
5. **Не обвинять в переплате на шатких данных.** Матч по названию не знает
   производителя, а предельные цены разных заводов отличаются в разы.
   Показывать потолок фактом со ссылкой на приказ, а не приговором.
6. **Персональные данные с фото** (ФИО, диагноз) не логировать в сыром виде.
7. **Дисклеймер** один раз и по делу: сервис не ставит диагноз и не
   заменяет врача.

## 6. Как встроить в интерфейс

Не «чат в углу», а часть продукта:

- **На главной** — крупная точка входа «Загрузите фото назначения»
  рядом с поиском. Это главный сценарий, он должен быть виден сразу.
- **На карточке препарата** (`/lekarstvo/[id]`) — кнопка «Спросить про этот
  препарат», чат открывается с уже подставленным контекстом.
- **Ответы карточками**, стилем существующих компонентов: `DrugCard`,
  `PharmacyCard`, `CourseCalculator`. Не изобретайте новый визуальный язык —
  дизайн-система уже есть в `app/globals.css` (переменные `--color-brand`,
  `--color-surface`, `--color-line`, `--color-ink`, `--color-muted`).
- **Карта** — переиспользуйте `LazyMap` / `MapView`: там уже цена на маркере,
  кластеризация и попап с кнопкой «Как добраться» в 2GIS.
- **Мобильный вид обязателен.** Проверяйте на ширине 375px: горизонтального
  скролла страницы быть не должно, широкие таблицы скроллятся внутри своего
  контейнера.

## 7. Что проверить перед сдачей

```bash
cd web
npx tsc --noEmit      # должно быть 0 ошибок
npm run build         # должно пройти
```

Ручной сценарий целиком: фото назначения → распознанные позиции →
подтверждение схемы приёма → расчёт курса → карточки с ценами → маршрут в
2GIS. Проверьте на реальном назначении, а не на «привет, как дела».

Отдельно проверьте поведение, когда данных нет: несуществующий препарат,
нечитаемое фото, город без аптек. Агент должен честно сказать, а не
сочинить.

## 8. Известные ограничения — не выдавайте их за фичи

- Цены пока по двум сетям (Еврофарма, Биосфера). Сравнение работает там,
  где позиция есть в обеих.
- Аптеки собраны по четырём городам, клиники — по тринадцати.
- Флаг `pharmacy.has_compounding` (аптеки с производственным отделом, где
  изготавливают болтушки и мази по прописи) в схеме есть, **данных нет** —
  заполняется вручную.
- 75% предельных цен взяты из приказа 2019 года; поле
  `drug_ref.price_cap_source` показывает, из какого именно. Сравнение с
  устаревшим потолком даёт ложную «переплату» — в интерфейсе такие случаи
  помечены флагом `capIsStale` и не показываются.
- Отзывы 2GIS получены ключом их веб-клиента; для продакшна нужен
  собственный доступ к Reviews API.
